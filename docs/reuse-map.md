# 图2现有任务复用边界

图2中的四类现有任务不会被原样复制到本仓库，而是按以下契约复用：

| 现有任务 | 本仓库复用内容 | 本仓库不做的事 |
|---|---|---|
| 每日赛程采集服务 | 官方页面连接、Task 1 稳定 fixture ID、日期、开赛时间、全部频道 | 不重新筛选比赛，不创建第二份赛程清单 |
| 纯海报 | Figure 1、Image2 数据库、频道图标、4:5 排版与品牌安全规则 | 不把历史海报事件当作本场事实 |
| 赛前 | 已选比赛、队名、比赛 ID、频道和原始开赛时间 | 不继承预测比分、预计首发或赛前观点作为赛后事实 |
| 赛后 | 官方结果、赛后证据、参赛球员、比分方向、赛后海报与视频 | 不发布到赛前预测标签 |

最终发布目标始终是 Pending Review 的 `赛后比分`。赢家、输家、红牌、伤病、进球和争议
画面必须由当前比赛证据支持；科林蒂安 0:1 桑托斯一类客队获胜场景必须表现客队庆祝、
主队失落，不能因为海报左右位置而反转。
